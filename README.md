# GPT Desk Pet

白紫色龙族少女桌宠「GPT」：安静、寡言，使用轻微的表情和动作陪伴工作。

![动作预览](pets/gpt-dragon/previews/actions.gif)

## 安装

1. 下载 [ZIP 安装包](packages/gpt-dragon/1.0.0/gpt-dragon.zip)。
2. 解压，将 `gpt-dragon` 文件夹放入 `~/.codex/pets/`；若设置了 `CODEX_HOME`，则放入其 `pets/` 子目录。
3. 重启 Codex，在宠物列表选择「GPT」。

也可直接复制本仓库 `pets/gpt-dragon/`。安装包不包含应用本体。

## 内容

- v2 透明图集，1536 × 2288，单格 192 × 208。
- 九组动作、十六方向视线。
- [视线预览](pets/gpt-dragon/previews/look.gif)。
- 安装包附 SHA-256 校验文件。
